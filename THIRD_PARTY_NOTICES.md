## AW-ELC HID protocol references

The platform query and `USB VID 187C / PID 0550` device details are based on the published protocol in [dell-g15-rgb](https://github.com/moalmatry/dell-g15-rgb) by Mohamed Almatry.

The verified Windows APIv4 per-zone command and light-ID mapping (`8`, `9`, `10`, `11`) are informed by [Dell G15 5515 Backlight Control](https://github.com/cnlove7777777-art/Dell-G15-5515-Backlight-Control), Copyright (c) 2026 G15 Backlight contributors. That project credits [alienfx-tools](https://github.com/T-Troll/alienfx-tools), Copyright (c) 2020 Rik Lain. The implementation in this repository is a separate Windows HID adapter and does not include those projects' source files.
